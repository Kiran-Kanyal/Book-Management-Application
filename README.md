Book Management System

A simple book management system built using React, Node.js, JavaScript, and MongoDB. This application allows users to manage a collection of books, including adding, editing, and deleting book entries.
Features

Add a Book: Users can add new books with details such as title, author, genre, and publication date.
Edit Book Details: Update information about books already in the system.
Delete a Book: Remove books from the system.
View Book List: Browse through a list of books.
Tech Stack

Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
API Testing: Postman (Used for backend testing but not included in the repo)
